# InMotus Design System

InMotus — самостоятельная дизайн-система для разных приложений. Репозиторий содержит CSS-токены, необязательные стили базовых компонентов, каталог интерфейсных приёмов, живой предпросмотр и Codex Skill. Он не зависит от структуры, функций или кода какого-либо приложения.

## Что можно выбрать отдельно

| Слой | Файлы | Когда брать |
| --- | --- | --- |
| Визуальный стиль | [`tokens/inmotus.css`](tokens/inmotus.css) | Нужны цвета, шрифт, размеры, скругления и тени InMotus |
| Базовые компоненты | [`components/inmotus.css`](components/inmotus.css) | Нужны кнопки, карточки, поля и демонстрационные элементы без UI-библиотеки |
| Приёмы интерфейса | [`patterns/interface.md`](patterns/interface.md) | Нужны навигация, адаптивные панели и характер движения, возможно с другой темой |
| Анимированные отклики | [`patterns/feedback.md`](patterns/feedback.md), [`motion/`](motion/) | Нужны растущие кнопки, эластичные капсулы, тумблеры и плавные списки/меню |
| Иконография | [`patterns/iconography.md`](patterns/iconography.md) | Нужны точный набор Hugeicons Stroke Rounded, соответствия иконок и правила размеров; можно заменить библиотеку |
| Инструкция для Codex | [`SKILL.md`](SKILL.md) | Хочется применять выбранные слои по запросу в других проектах |

Каждый слой можно пропустить. CSS-классы и переменные имеют префикс `inmotus`, поэтому их можно подключать постепенно. React, Tailwind и другие UI-библиотеки **не требуются**.

## Как использовать в новом проекте

### Вариант 1: отправить ссылку Codex

В новом чате можно написать:

> Используй дизайн-систему https://github.com/morphw/inmotus-design-system версии v0.4.0, включая стандартные анимированные отклики. Возьми визуальный стиль, иконки и мобильную навигацию, но оставь остальные библиотеки и функции проекта. Сначала посмотри репозиторий и существующую структуру моего проекта.

Если репозиторий приватный, среде Codex нужен доступ к GitHub или локальная копия. Одна ссылка сама по себе доступ не выдаёт. Вместо ссылки можно указать путь к локальной копии или приложить архив.

### Вариант 2: подключить файлы к проекту

Скопируй `tokens/inmotus.css` в проект и импортируй его. Оберни нужную часть интерфейса в элемент с классом `inmotus-theme`:

```html
<div class="inmotus-theme" data-inmotus-theme="light">
  <!-- приложение -->
</div>
```

Для тёмной темы поставь `data-inmotus-theme="dark"`. При необходимости подключи `components/inmotus.css` после токенов. Пример: [`preview/index.html`](preview/index.html). Токены имеют значения внутри `.inmotus-theme`, поэтому они не оформляют остальные части страницы.

Для полного интерфейса подключи также `motion/inmotus.css` после компонентов и установи `installPressFeedback()` из `motion/inmotus.mjs` один раз при запуске приложения. Кнопки и списки используют браузерные API. Эластичные индикаторы подключаются к выбранным пунктам через `createElasticSelection`, тумблеры — через `createElasticIndicator`; им передаются `animate` и `motionValue` из Motion или совместимого движка. Готовые примеры и точные параметры: [`patterns/feedback.md`](patterns/feedback.md). Отклики входят в стандартное применение InMotus к новому приложению; конкретные элементы или весь слой можно исключить.

Эталонный режим откликов — `data-inmotus-feedback="full"`. Для следования системному уменьшению движения выбери `system`, для отключения — `off`. Эти режимы доступны и без темы InMotus. Крупные переходы страниц и декоративные анимации отдельно учитывают системные настройки.

Можно хранить репозиторий как Git submodule, отдельный пакет или просто копировать выбранные файлы. Для одного проекта удобнее начать с копирования; для нескольких проектов, которые регулярно получают обновления, подходит submodule или пакет.

### Вариант 3: подключить Skill

Папка этого репозитория одновременно является Codex Skill: в корне лежит `SKILL.md`. Чтобы Skill был доступен в разных задачах на одном компьютере, помести **всю папку** репозитория в каталог личных навыков Codex (`~/.codex/skills/inmotus-design-system`) или создай на неё ссылку. Если работаешь только в одном проекте, можно держать папку в проектном каталоге навыков. После этого попроси: «Используй `$inmotus-design-system`, но только приёмы интерфейса; тему и библиотеки оставь текущие».

Skill читает файлы этого репозитория. Он не должен молча заменять выбранные проектом библиотеки или оформление.

## Версии и обновление

- Релиз `v0.4.0` переносит стандартные анимированные отклики: увеличение кнопок, движение двух краёв и раздувание капсул, тумблеры, списки, меню и шторки. При обновлении с `v0.3.0` кнопка теперь растёт до `1.06` вместо уменьшения до `0.98`; подключи слой `motion/`, чтобы короткий тап и клавиатура получили полный возврат. Новые файлы не подключаются автоматически к ранее скопированным приложениям.
- Релиз `v0.3.0` добавляет отдельный слой иконографии с точным бесплатным набором Hugeicons Stroke Rounded и правилами применения.
- Релиз `v0.2.0` — первая версия под самостоятельным названием InMotus Design System. В ней сохранены визуальные параметры предыдущего релиза и обновлены все имена и префиксы.
- Новые проекты могут выбрать актуальный релиз, а существующие — оставаться на закреплённой версии.
- Меняй `tokens/inmotus.css` как источник значений. После изменения цветов запускай `node scripts/export-tokens.mjs`; он обновит совместимый JSON-экспорт `tokens/inmotus.tokens.json`.
- Перед обновлением проекта сравни выбранную версию с новой и перенеси только нужные слои. Изменения в этом репозитории сами по себе не меняют другие приложения.

## Границы системы

Этот репозиторий определяет оформление и приёмы интерфейса. В нём нет бэкенда, календаря, данных пользователя, логотипа продукта и прикладных модулей. Дизайн-систему можно развивать и версионировать независимо от любого приложения, которое её использует.

Открой [`preview/index.html`](preview/index.html), чтобы увидеть оба режима и базовые элементы без сборки и зависимостей. В этом статическом примере иконки схематичные; точный набор для приложений описан в [`patterns/iconography.md`](patterns/iconography.md).

Интерактивные анимации показаны отдельно в [`preview/motion.html`](preview/motion.html). Из корня репозитория запусти `python -m http.server 8080` и открой `http://localhost:8080/preview/motion.html`. Демонстрация капсул требует интернет для загрузки Motion из CDN; в рабочем проекте используй пакет своего проекта. Пример проверен с Motion `12.42.2`; [документация движка](https://motion.dev/docs/animate).
