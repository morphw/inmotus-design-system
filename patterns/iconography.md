# Иконография InMotus

Этот слой можно подключать отдельно от цветов, компонентов и приёмов интерфейса. Для наиболее точного совпадения с визуальным языком InMotus используй **Hugeicons Free, стиль Stroke Rounded**. В React это `@hugeicons/react` вместе с `@hugeicons/core-free-icons`. Бесплатный набор и код рендера имеют лицензию MIT; Pro-набор для InMotus не нужен. Сам репозиторий не включает файлы иконок и не требует этих пакетов для работы CSS.

## Характер и размеры

- Линейные, округлые иконки без смешения с залитыми наборами в одной группе элементов. Сохраняй исходные пропорции и сетку набора; не рисуй случайные замены вручную.
- Базовый размер — `20px`, толщина линии — `1.7`, цвет — `currentColor`. Цвет наследуется от текста или контейнера, поэтому одна иконка работает в обеих темах и состояниях.
- Боковая навигация: `18–19px`; мобильная нижняя навигация: `22px`; меню и действия: `18–20px`; компактные статусы: `14–17px`; крупные иконки разделов: `23–24px`.
- Толщину `1.9–2.2` используй локально для маленьких, активных или важных управляющих иконок. Не утолщай весь набор: лёгкий контур — часть стиля.
- Для разделов подходит контейнер `48×48px` со скруглением `16px`: акцентная заливка с белой иконкой или спокойная акцентная подложка с цветной иконкой. Для компактного акцента — `28×28px`, скругление около `8px`, иконка `17px`.
- Одинаковое действие в разных местах обозначай одной и той же пиктограммой. Смысл нового продукта определяет выбор иконки; перечень разделов конкретного приложения не переносится.

## Подключение

Для React установи только иконный слой, если он выбран проектом:

```bash
npm install @hugeicons/react @hugeicons/core-free-icons
```

```tsx
import { HugeiconsIcon } from "@hugeicons/react";
import Search01Icon from "@hugeicons/core-free-icons/Search01Icon";

<HugeiconsIcon icon={Search01Icon} size={20} strokeWidth={1.7} color="currentColor" aria-hidden="true" />
```

В интерфейсе, из которого взяты параметры, использованы версии `@hugeicons/react` `1.1.7` и `@hugeicons/core-free-icons` `4.2.1`; эти версии служат точным ориентиром при воспроизведении вида, а не обязательным ограничением для новых проектов. Если в другом стеке доступен этот же набор, используй его штатный рендерер. Если выбрана другая библиотека, подбери близкие по смыслу округлые линейные пиктограммы и сохрани размеры, цвет, толщину и контейнеры из правил выше. Не добавляй Hugeicons вопреки выбору пользователя или правилам проекта.

Необязательный CSS-слой предоставляет `.inmotus-icon-badge` для спокойной подложки, модификатор `.inmotus-icon-badge--solid` для сплошного акцента и `.inmotus-icon-badge--small` для компактного размера. Акцент задаётся `data-accent="blue|green|orange|purple|red"`; размер SVG задаёт приложение.

Иконка рядом с видимым текстом декоративна: скрывай её от скринридера. Отдельная кнопка с иконкой должна иметь доступное название на кнопке (`aria-label` или видимый текст). Цвет не должен быть единственным способом различить действие или состояние.

Статический [`предпросмотр`](../preview/index.html) содержит схематичные SVG для работы без сборки; точные формы иконок задаёт набор Hugeicons. [Установка и примеры](https://hugeicons.com/docs/integrations/react/quick-start), [лицензия бесплатного набора](https://hugeicons.com/docs/faqs/license-questions).
