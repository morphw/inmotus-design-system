# Отклики InMotus

При подключении всей InMotus к новому проекту эти отклики входят в стандартный интерфейс. Применяй их к подходящим элементам, сохраняя выбранные пользователем исключения. Один характер движения объединяет кнопки, мобильную навигацию, сегменты, тумблеры и всплывающие поверхности. При переносе только палитры этот слой можно пропустить.

## Точные параметры

| Элемент | Отклик |
| --- | --- |
| Кнопки, кнопки с иконкой, триггеры списков | При удержании увеличиваются до `1.06` за `90ms`, кривая `cubic-bezier(0.2, 0, 0, 1)`. Отпускание: `1.06 → 1.012 → 1` за `360ms`; промежуточная точка на `70%`, первый участок `cubic-bezier(0.16, 1, 0.3, 1)`, последний `ease-in-out`. Короткий тап и клавиатурное нажатие показывают полный возврат. |
| Активная капсула мобильного навбара | Анимируются обе границы, а не только позиция. Передний край: spring `320ms`, задний: spring `480ms`, `bounce: 0`; при движении в другую сторону края меняются ролями. Одновременно фон раздувается до `scaleX: 1.04`, `scaleY: 1.08`, затем возвращается к `1` за `480ms`; пик на `35%`, кривая `cubic-bezier(0.32, 0.72, 0, 1)`. Подложка выходит на `4px` за края пункта с каждой стороны. |
| Сегменты | Та же капсула с измерением реальной ширины выбранной кнопки, без дополнительных `4px`. Фон движется отдельно от текста и иконок. |
| Тумблер | Та же модель двух краёв и раздувания. Эталон: дорожка `3.35rem × 2rem`, внутренний отступ `0.25rem`, круг `1.5rem`, ход `1.35rem`. После движения круг снова становится круглым. |
| Выпадающий список | Открытие `320ms`: opacity `0 → 1`, scale `0.9 → 1`, y `-6px → 0`; кривая `cubic-bezier(0.32, 0.72, 0, 1)`. Закрытие `180ms`: opacity `1 → 0`, scale `1 → 0.96`, y `0 → -6px`; кривая `cubic-bezier(0.32, 0, 0.67, 0)`. При размещении над триггером смещение меняется на `+6px`. Origin привязан к стороне триггера. |
| Меню действий / контекстное меню | Те же параметры появления; при закрытии y `0 → -4px`. Origin обычно `top right`, либо реальная точка привязки меню. |
| Мобильное меню действий | Нижняя шторка и оверлей открываются/закрываются за `400ms`. Для шторки с жестами сохраняй анимацию её библиотеки и меняй только длительность. Не применяй одновременно CSS-transform и transform жестового движка. |

Переходы страниц `180ms`, боковой панели `400ms` и обычные переходы цветов `150–200ms` остаются отдельными от этих откликов. Не заменяй длительность капсулы длительностью смены страницы.

## Готовые файлы

- [`../motion/inmotus.css`](../motion/inmotus.css): нажатие, появление/закрытие списков и меню, шторка и режимы движения. Подключай после базовых компонентов.
- [`../motion/inmotus.mjs`](../motion/inmotus.mjs): общие параметры, обработчик быстрых/клавиатурных нажатий и движок эластичной капсулы. Не содержит React, маршрутов, иконок или продуктовых данных.
- [`../preview/motion.html`](../preview/motion.html): интерактивный эталон откликов. Открывается через локальный HTTP-сервер; капсула в примере загружает Motion из CDN, для неё нужен интернет.

Кнопки и всплывающие поверхности используют CSS и Web Animations API без дополнительных пакетов. Для точной пружинной капсулы передай `animate` и `motionValue` из пакета `motion` (эталон проверен с `12.42.2`). Если проект выбрал другую библиотеку, перенеси модель двух краёв и параметры в неё. Обычная transition позиции без разницы скоростей краёв не воспроизводит этот эффект.

## Кнопки

```js
import { installPressFeedback } from './inmotus/motion/inmotus.mjs';
const dispose = installPressFeedback(); // Один обработчик на документ.
// При уничтожении приложения: dispose().
```

Стандартный обработчик документа охватывает кнопки внутри `.inmotus-theme` или контейнера с `data-inmotus-feedback`, включая добавленные позже. Для другого оформления можно вызвать `installPressFeedback(rootElement)`. Порталы оформляй тем же классом темы/режимом либо передай общий контейнер; обработчик документа должен быть установлен один раз. В React устанавливай его через `useEffect(() => installPressFeedback(), [])`: возвращаемая функция удаляет обработчики и отменяет анимации.

- `data-inmotus-press="none"`: исключить жестовые элементы, ручки перетаскивания и другие элементы с собственным откликом.
- `data-inmotus-press="content"` на кнопке: увеличивать только первый дочерний HTML-элемент, сохраняя размер самой строки/области нажатия. Для SVG используй обёртку `span`.
- `data-inmotus-press="button"` на ссылке: дать ей отклик кнопки. Обычные текстовые ссылки не масштабируются автоматически.

Disabled-элементы и пункты меню не увеличиваются. Прокрутка пальцем более `10px`, pointercancel и отпускание вне исходной области не запускают возврат. Обработчик не отменяет событие и не задерживает действие. Используется отдельное CSS-свойство `scale`, чтобы не стереть transform позиционирования кнопки. Отводи место для увеличения и проверяй обрезание родительским overflow.

## Навбар и сегменты

Контейнер имеет `position: relative`; его пункты и декоративный индикатор используют один offset parent. Индикатор абсолютный, `aria-hidden="true"`, `pointer-events: none`; подписи остаются отдельными соседними элементами с более высоким z-index. Базовые стили выбранной кнопки не должны рисовать вторую подложку поверх движущейся.

```js
import { animate, motionValue } from 'motion';
import { createElasticSelection } from './inmotus/motion/inmotus.mjs';
const capsule = createElasticSelection(container, indicator, items,
  { animate, motionValue }, { bleed: 4 }); // Для сегментов bleed: 0.
capsule.select(items[initialIndex]); // Первый рендер: сразу на месте, без пульса.
// После смены состояния/маршрута:
capsule.select(items[nextIndex]);
// При размонтировании: capsule.destroy().
```

Состояние и семантику задаёт приложение: ссылки навигации получают `aria-current`, сегменты — `aria-pressed` или полный паттерн вкладок с клавиатурой. Утилита только рисует фон. При изменении размеров ResizeObserver переставляет индикатор сразу; первая нотификация наблюдателя не обрывает выбор. Быстрые повторные нажатия отменяют старое движение и продолжают от текущих значений обоих краёв и раздувания. При обновлении списка пунктов пересоздай адаптер. Скрытый контейнер измеряй после его появления; при изменении расположения без resize заново вызови `select(item, { animate: false })`.

## Тумблеры

```js
import { createElasticIndicator } from './inmotus/motion/inmotus.mjs';
const thumb = createElasticIndicator(thumbElement, { animate, motionValue },
  { unit: 'rem', minimumWidth: 1.5 });
function renderSwitch(checked) {
  const left = checked ? 1.35 : 0;
  thumb.setBounds(left, left + 1.5);
  switchButton.setAttribute('aria-checked', String(checked));
}
renderSwitch(initialChecked);
// При размонтировании: thumb.destroy().
```

Помести круг в отдельную внутреннюю дорожку после отступа `0.25rem`; она служит offset parent. Родительская кнопка имеет `role="switch"`, доступное название, controlled checked-состояние и стандартное управление Space/Enter. Disabled не меняет состояние. Начальный checked не вызывает раздувание. При повторном переключении во время движения круг продолжает с текущего положения. Размеры в rem сохраняют поведение при изменении базового шрифта.

## Выпадающие списки, меню и шторки

Добавь `.inmotus-popup-motion` на отдельную анимируемую поверхность, меняй `data-state="open|closed"`; для меню добавь `.inmotus-menu-motion`, для выпадающего списка над триггером `data-side="top"`. Radix Select передаёт origin через `--radix-select-content-transform-origin`; другая библиотека может задать transform-origin сама. Если движок позиционирования использует transform, оставь его на внешнем контейнере, а анимацию применяй к внутренней поверхности.

Сохраняй закрываемую поверхность в DOM до окончания её exit-анимации. Сразу при закрытии отключай действия: `pointer-events: none`, `inert`, `aria-hidden`; затем удаляй. Возвращай фокус на триггер по правилам выбранного доступного компонента. При повторном открытии отменяй запланированное удаление. Escape в дочернем списке закрывает сначала список, сохраняя родительский диалог. CSS не реализует клавиатуру, фокус, выбор, позиционирование или стек модальных окон — используй существующую механику проекта.

Для самостоятельной шторки доступны `.inmotus-action-sheet-motion` и `.inmotus-sheet-overlay-motion`. Для Vaul или другого жестового компонента используй `.inmotus-action-sheet-timing` на контенте и оверлее: сама библиотека сохраняет жесты и траекторию. В другом стеке переводятся те же состояния и времена.

## Режим движения

Эталонные отклики `full` сохраняются даже при `prefers-reduced-motion`, как в интерфейсе, из которого взяты эти параметры. Корневой `data-inmotus-feedback="system"` отключает пространственные отклики, когда система сообщает уменьшение движения; `off` отключает их всегда. По умолчанию используется `full`, который можно указать явно. Выбор пользователя и требования нового проекта имеют приоритет. Эти режимы относятся к откликам; для страниц, крупных панелей и декоративного движения продолжай учитывать системное уменьшение движения.

После изменения режима переставь активную капсулу с `{ animate: false }`; последующие действия прочитают актуальный режим. Не копируй постоянное `reducedMotion="never"` на всё приложение.

## Проверка переноса

Проверь короткий тап, удержание, Enter/Space, disabled, прокрутку и отмену жеста. У капсулы проверь начальный рендер, оба направления, быстрый разворот, разные ширины пунктов и resize: фон растягивается, текст остаётся неподвижным, в конце геометрия точная. Для списка проверь открытие вверх/вниз, видимую exit-анимацию, отсутствие повторного действия во время закрытия, возврат фокуса и вложенный диалог. Повтори в светлой/тёмной теме и выбранных режимах движения.
